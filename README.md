# Presupuesto Express - Calculadora de Cotizaciones

Una aplicación web interactiva y ligera diseñada para calcular presupuestos y cotizaciones en tiempo real. Permite gestionar conceptos, calcular subtotales y totales automáticamente, validar entradas de datos y mantener la información guardada localmente.

## 🚀 Prerrequisitos

Para ejecutar este proyecto en tu entorno local no necesitas un servidor Node.js ni bases de datos complejas. Únicamente requieres:

* Un navegador web moderno (Google Chrome, Mozilla Firefox, Microsoft Edge o Safari).
* Conexión a internet (para cargar la CDN de Tailwind CSS y Lucide Icons).

---

## ⚙️ Variables de Entorno

Este proyecto no requiere variables de entorno (`.env`), ya que se ejecuta directamente del lado del cliente (*Client-Side Rendering*) y utiliza `LocalStorage` para la persistencia de datos.
